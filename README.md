# Car-Price-Prediction
End-to-end ML pipeline predicting used-car prices in Azerbaijan from 223,758 cleaned turbo.az listings. Compares 11 regression models (Random Forest, XGBoost, LightGBM, stacking) using leak-free scikit-learn pipelines and target encoding. Best model: Random Forest with R² 0.955 and MAE 2,368 AZN, 60% below the linear baseline.
